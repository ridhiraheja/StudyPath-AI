The official UCI Student Performance dataset is downloaded here by `python train_model.py`.

Source: Cortez, P. (2008). Student Performance. UCI Machine Learning Repository.
https://doi.org/10.24432/C5TG7T.

The dataset is licensed CC BY 4.0. The two source CSVs are not bundled in this ZIP; the training script downloads them from the official UCI archive on first run.
